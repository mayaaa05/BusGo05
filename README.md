# 📁 Important Files Summary - BusGo

This folder contains direct copies of the most essential files in the project for quick access and reference:

| File | Type | Description |
| :--- | :--- | :--- |
| **`server.js`** | Backend | Core Express server, API routes, and static frontend hosting. |
| **`db.js`** | Database | MongoDB connection manager with auto-fallback to built-in DB. |
| **`package.json`** | Config | Master project dependencies, scripts (`build`, `start`, `postinstall`). |
| **`render.yaml`** | Deployment | 1-Click deployment blueprint for Render.com. |
| **`vercel.json`** | Deployment | Rewrite configuration to prevent 404 errors on Vercel. |
| **`App.jsx`** | Frontend | Main React routing file with all user and admin views. |
| **`api.js`** | Frontend | Axios client configured for both local and production API calls. |
| **`SeatMap.jsx`** | Component | Interactive bus seat selection visualizer. |
| **`TicketCard.jsx`** | Component | Passenger ticket with QR code generation. |
| **`.env.example`** | Config | Environment variables template. |
| **`BusGo_Project_Report.docx`** | Report | Complete 70-page project documentation report. |
